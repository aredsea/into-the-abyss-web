# r4b 검수 기록

- Chromium / 390×844·360×780에서 마을·동료 목록·전투 스크린샷을 직접 열어 보았습니다. 동료 흰 사각 배경이 없고 이름·상태·기본 조작이 표시되는 것을 확인했습니다.
- 30명 컷인 스크린샷은 실제 게임에서 촬영하고, 3장 모음으로 직접 열어 상반신 표시를 검토했습니다. 원래 초상을 투명화한 것이 아니라 새 도트를 상반신 범위로 표시합니다.
- 두 크기의 원정·시설·영입·장비·귀환·저장 흐름 검사 통과.
- 두 크기에서 각 30명 미리보기 총 60회, 저장 상태 불변과 페이지 오류 없음 확인.
- 실제 힐데가르트 고유 기술: 두 크기와 감소된 모션 설정에서 MP 10 소모·행동 횟수 1회 증가·재생 후 다음 행동 진행 확인.
- 원본 사본 39개, 새 도트 30개 SHA-256 대조 통과. 이번 변경에서 이미지 파일의 픽셀을 수정하지 않았습니다.
