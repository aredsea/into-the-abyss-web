부족한 점: 8개 장소의 갈림길 1차 구현과 실제 로딩 화면을 게임에 반영했다. 확장 제안 전체를 구현한 것은 아니다. 로딩 삽화는 1차 시안이고 PNG 2.37 MB의 경량화가 남았다. 삽화의 세밀한 재질과 기존 전투 도트의 화풍 차이가 있다.

확인하지 못한 점: 레퍼런스 게임을 이번 작업에서 직접 플레이하지 않았다. 공식 설명·공개 스크린샷을 조사했고 5개 게임의 화면을 직접 열어 봤다. Meteorfall은 공식 모바일 설명을 확인했다. 실물 휴대폰·Safari 검수, 느린 네트워크의 실제 게임 로더, 제안 원정의 재미·밸런스는 미검증이다.

# 웹 원정 구조와 로딩 시안

[조사와 적용안](index.html) · [로딩 상태 시안](loading.html)

## 파일

- `index.html`: 6종의 플레이·진행·UI 비교, 출처 링크, 적용안, 첫 시제품 가설, 읽힘 답안표.
- `loading.html`: 다운로드·시작 준비·오류 상태를 수동 선택하는 시안. 진행률 62%는 명시된 예시값.
- `assets/academy-loading-v1.png`: 새로 생성한 1024×1536 원본 삽화. 캐릭터·문자·진행 막대 없음.
- `asset-spec.json`: 내장 imagegen 도구에 보낸 전체 프롬프트, 규격, SHA-256, 색·글꼴·구성 기준.
- `qa/`: 두 화면 크기의 검사 결과와 로딩 스크린샷.

## 확인

Chromium 390×844와 360×780에서 보고서의 가로 넘침 없음, 로딩 이미지 표시, 로딩 화면의 화면 내 배치, 44px 이상 버튼, 시작 준비에서 퍼센트 숨김, 오류 후 시안 재시도 전환을 검사했다. 두 로딩 스크린샷과 360 오류 화면을 직접 열어 보았다.

최초 조사에서는 게임을 수정하지 않았다. 후속 지도·로딩 구현 기록은 루트 ROUTE-PROTOTYPE.md에 있다. 봇 원본과 캐릭터 에셋은 변경하지 않았다. 공식 스크린샷은 로컬 조사 자료로만 읽고 공개 저장소에 복사하지 않았다. 조사 페이지에서 제작사 소개와 원본 화면으로 연결한다.
